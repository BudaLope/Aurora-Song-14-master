# Reporting a security vulnerability
You can report a security vulnerability through Discord or through email.

If you want to send an email, you can contact us at <github@aurorasong.gay>.
If you want to contact us through Discord, you can join [our server](https://discord.gg/aurorasong)
and then **privately** message anyone with the `@Maintainer` role.

In either case, **do not publicly disclose the vulnerability until we explicitly give
you permission to do so**.
